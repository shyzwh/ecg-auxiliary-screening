# 用户手册

## 1. 系统简介

ECG 心电风险可解释辅助筛查系统 v2.1.0 用于单导联 ECG 的科研、教学和初步辅助筛查。系统通过预处理、R 峰检测、12 项特征提取、1D-CNN 异常心拍定位和 XGBoost 风险分级生成结果。

系统有六个页面：

1. 心电分析
2. 历史记录
3. 病例教学
4. 病情统计
5. 系统设置
6. 关于项目

## 2. 启动

在项目根目录执行：

```powershell
streamlit run app.py
```

浏览器打开：

```text
http://localhost:8501
```

第一次启动需要加载 TensorFlow/CNN 等模型，等待页面显示“心电分析”即可。

## 3. 心电分析

### 3.1 填写患者信息

“管理个人信息”区域可以填写：

- 姓名
- 年龄
- 性别
- 身高
- 体重
- 既往病史
- 用药情况

姓名用于本地记录，历史页面会做展示层脱敏。年龄和性别用于输入校验及部分特征判读。

### 3.2 填写症状

症状描述为可选项，例如胸闷、心悸、运动后不适等。症状会随本次分析结果保存，并可作为可选 GLM 辅助解读的输入。不要填写与患者无关或无法确认的内容。

### 3.3 上传 ECG

支持：

- CSV
- TXT
- DAT

页面提供“加载示例数据”按钮。DAT 文件需要配套 `.hea` 等文件；单独上传 DAT 通常不足以完成读取。底层加载器支持 NPY，但当前页面上传控件不把 NPY 列为可选扩展名。

### 3.4 开始分析

点击“开始分析”后，系统按以下顺序处理：

1. 读取 ECG 和采样率。
2. 清理无效信号值。
3. 抑制 50/60 Hz 工频干扰。
4. 执行 0.5 至 40 Hz 带通滤波、基线校正和中值滤波。
5. 检测 R 峰。
6. 提取 HR、PR、QRS、QT、QTc、ST_shift、P_amp、T_amp、RR_mean、RR_std、SDNN、RMSSD。
7. 使用 CNN 定位异常心拍。
8. 使用 XGBoost 输出整体风险等级和概率。
9. 生成 SHAP 解释和规则报告。

## 4. 查看分析结果

### 核心结论与波形

查看风险等级、风险评分、心率、总心拍数、异常心拍数和采样率。波形图会标记清洗信号、R 峰和异常心拍位置。

### 临床特征

12 项特征按以下分组显示：

- 节律稳定性：HR、RR_mean、RR_std、SDNN、RMSSD。
- 传导功能：PR、QRS。
- 复极状态：QT、QTc、ST_shift、T_amp。
- 波形形态：P_amp。

特征状态由规则阈值判定为正常、轻度异常或显著异常。它不是医生诊断。

### SHAP 可解释性

SHAP 用来解释 XGBoost 的特征贡献。页面可能显示特征贡献条形图、全局蜂群图、QRS/ST_shift 交互图和单样本决策力图。全局和交互图依赖 `training_data.csv`、模型文件和完整特征列，数据不足时页面会提示不可用。

### 筛查报告

报告包含风险分级、概率、异常心拍数量、特征判读、动态描述和综合建议。离线规则报告不依赖外部 API，默认作为稳定结果。

## 5. 两条模型通路

- 1D-CNN：按心拍分析，负责异常心拍定位。
- XGBoost：按 12 项数值特征分析，负责低危、中危、高危分级。
- SHAP：解释 XGBoost 特征贡献。

CNN 和 XGBoost 独立输出，不自动融合为一个新模型结果。实际使用时应同时查看波形、特征和报告。

## 6. AI 润色、智能解读和问 AI

系统可以选择配置 GLM API，用于报告润色、结构化辅助解读和知识库问答。GLM 不负责核心 ECG 风险判定。

当前 fallback 顺序为：

```text
glm-4-flash-250414
glm-4-flash
glm-4.7-flash
```

单个模型返回 429 或超时后会尝试下一个模型，每个模型最多一次。全部失败时：

- AI 润色回退到离线建议。
- 智能解读显示服务暂时不可用。
- 问 AI 保留离线报告和专业咨询提示。

API 密钥不会作为普通页面内容展示。密钥应使用 Streamlit Secrets 或环境变量，不要提交到 Git。

本地知识库位于 `knowledge/ecg_diseases.json`。问 AI 时，系统先按疾病名称、分类和关键词检索最多 5 条相关内容，再把检索结果交给可选 GLM 生成回答。

## 7. 历史记录

在报告区域点击“保存到历史记录”，数据会写入 `storage/ecg.db` 的 `records` 表。当前表有 13 个字段：

```text
record_id, 时间, 文件名, 风险等级, 风险评分, 总心拍数,
异常心拍数, 备注, 报告, 特征, patient_name, patient_info, symptoms
```

历史页面支持：

- 按患者查看记录。
- 查看筛查时间线。
- 查看风险、特征、症状和完整报告。
- 导出报告文本。
- 删除记录。

历史记录保存文本、特征和统计信息，不等同于完整原始 ECG 归档。删除前确认当前记录和患者身份。

## 8. 病例教学

病例教学读取 `config/cases.json`，可选择内置病例查看：

- 病例类别和难度。
- 风险等级。
- ECG 特征。
- 临床分析。
- SHAP 解释文字。
- 学习要点和处理建议。

教学病例不是患者诊断案例，不应直接套用到真实患者。

## 9. 病情统计

病情统计从 SQLite 历史记录读取数据，展示：

- 总筛查人数。
- 高危数量。
- 平均年龄。
- 男女比例。
- 高危病例列表。
- 风险等级分布。
- 异常特征频率。
- 按日期的筛查趋势。

没有历史记录时页面显示空状态，不代表患者风险为零。

## 10. 系统设置

设置页可以修改：

- 中危阈值和高危阈值。
- XGBoost 模型路径。
- CNN 模型路径。
- 是否显示 SHAP。
- 页面主题。
- 自定义 API 是否使用、模型名称和接口地址。

模型路径必须指向实际存在且相互匹配的文件。修改阈值只影响页面配置和规则相关逻辑，不能把评估指标改成更高的结果。

## 11. 评估结果和限制

当前评估结果来自项目保存的 `results/model_evaluation.json`：

| 模型 | 准确率 | 数据划分 | 备注 |
|---|---:|---|---|
| XGBoost | 0.90 | 分层 80/20 | 高危敏感性未能验证 |
| 1D-CNN | 0.9800 | 分层 80/20 | 参数量 43,521 |

XGBoost 评估样本总数为 47，留出集 10；CNN 样本总数为 29,759，留出集 5,952。CNN 标签是 normal/abnormal，心律失常细分类未能验证。当前未进行外部临床数据集验证。

## 12. 安全使用和医学免责声明

不要在公开环境上传未经授权的真实患者资料，不要把姓名、联系方式、病历或 API 密钥提交到仓库。系统结果只用于科研、教学和辅助筛查，不能替代执业医师的诊断、治疗或急救判断。不得依据系统结果自行停药、换药或延误就医。出现胸痛、呼吸困难、晕厥、持续心悸等症状时，应立即联系急救机构或前往医院。
