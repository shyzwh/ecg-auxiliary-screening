## 系统简介

本系统是一套基于 Streamlit 的单导联 ECG 风险辅助筛查工具，面向基层医护、科研教学和初步筛查场景。

系统对输入心电信号进行预处理、R 峰检测和临床特征提取，然后通过两条相互独立的通路进行分析：

- 1D-CNN 形态通路：定位可能异常的心拍。
- XGBoost 数值通路：基于 12 项 ECG/HRV 特征输出低危、中危、高危风险等级。
- SHAP 解释模块：解释 XGBoost 12 项临床特征对当前结果的贡献。

两条通路的结果不会被系统自动融合，医护人员需要结合波形、特征、临床信息和复核状态进行判断。

## 适用场景

- 社区卫生服务中心的初步心电筛查。
- 校园体检和学生健康筛查。
- 基层门诊的辅助分析。
- 心电信号处理、机器学习和可解释 AI 的科研教学。

系统目前仅适用于单导联 ECG，不支持 12 导联 ECG 输入。

## 运行环境要求

- Windows、Linux 或 macOS 均可运行，当前开发环境为 Windows。
- Python 3.10 或更高版本。
- 可用浏览器，例如 Edge、Chrome 或 Firefox。
- 建议至少 4 GB 可用内存；使用较长 ECG 文件时需要更多内存。
- 项目依赖包括 Streamlit、NumPy、Pandas、SciPy、WFDB、NeuroKit2、XGBoost、SHAP、TensorFlow、Plotly、ReportLab 等。
- 系统使用预训练模型进行推理，不在网页分析流程中在线训练模型。

## 安装与启动方法

### 1. 打开项目目录

在 PowerShell 中进入项目根目录：

```powershell
cd "D:\桌面\王涵—AI 护心镜—基于深度学习异常定位与可解释XGBoost 的心电风险辅助筛查系统-最终版\ECG-Auxiliary-Screening"
```

### 2. 创建虚拟环境

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

如果只缺少 PDF 功能依赖，也可以单独安装：

```powershell
pip install reportlab
```

### 4. 启动系统

必须在项目根目录执行：

```powershell
streamlit run app.py
```

默认访问地址：

```text
http://localhost:8501
```

系统启动后使用左侧导航栏切换页面。

## 功能说明

### 心电分析

心电分析页面用于完成一次新的筛查：

- 输入患者姓名、年龄和本次分析性别。
- 上传 CSV、TXT 或 DAT 格式的 ECG 文件。
- 点击“加载示例数据”使用项目内 MIT-BIH 100 号记录。
- 点击“开始分析”执行预处理、R 峰检测、特征提取、CNN 推理、XGBoost 推理、SHAP 分析和报告生成。
- 查看风险等级、双通路结果、置信度、复核状态、波形、12 项特征、SHAP 图和结构化建议。
- 支持下载 TXT 和 PDF 报告。
- 支持复制报告内容和打开打印友好视图。
- 分析结果会保存在当前 Streamlit 会话中，页面切换后仍可查看。

上传文件应包含可读取的心电数值。CSV/TXT 文件通常需要时间列和电压列；DAT 文件需要同目录下存在对应的 HEA 文件，例如 `100.dat` 必须配套 `100.hea`。

### 历史记录

历史记录页面使用 JSON 文件保存记录，默认位置为 `storage/records.json`。每条新记录包含：

- 患者信息。
- 输入文件元数据。
- 风险等级、风险评分和双通路结果。
- CNN、XGBoost 置信度和复核状态。
- 12 项特征、SHAP 结果和健康建议。
- 清洗波形的独立文件引用。
- 报告和配置快照。

历史页面支持：

- 按风险等级筛选。
- 按文件名搜索。
- 导出筛选后的历史 CSV。
- 查看患者信息、输入文件信息、波形、R 峰、异常心拍和 SHAP 图。
- 导出历史记录的 TXT 或 PDF 报告。
- 删除当前选中的历史记录。

清洗波形单独保存在 `storage/waveforms/` 下，文件名使用记录 ID。不要随意删除该目录中的文件，否则对应历史记录可能无法恢复完整波形。

### 系统设置

系统设置页面可修改以下内容：

- 中危和高危风险阈值显示配置。
- XGBoost 模型路径。
- 1D-CNN 模型路径。
- 带通滤波上下限。
- 工频频率模式：自动、50 Hz 或 60 Hz。
- 是否显示 SHAP 图和 R 峰。
- QTc 男性正常上限。
- QTc 女性正常上限。
- QTc 未指定性别正常上限。
- QTc 显著异常起始上限。
- 默认性别。
- 可选的大模型服务商、端点和模型名称配置。

设置保存到 `config.json`。当前大模型配置仅作为可选接口配置，默认分析流程使用本地规则建议，不依赖大模型 API。

## 操作流程

### 1. 上传数据

1. 启动系统并进入“心电分析”。
2. 填写患者姓名和年龄；姓名可以填写脱敏编号。
3. 选择本次分析性别。该选择优先于系统设置中的默认性别。
4. 选择以下任一方式输入数据：
   - 上传 CSV 文件。
   - 上传 TXT 文件。
   - 上传配套完整的 MIT-BIH DAT 文件。
   - 点击“加载示例数据”使用 MIT-BIH 100 号示例记录。

### 2. 开始分析

点击“开始分析”。系统依次完成：

1. ECG 文件读取。
2. 带通滤波、工频处理、中值滤波和基线校正。
3. Pan-Tompkins R 峰检测。
4. 12 项 ECG/HRV 特征提取。
5. 1D-CNN 异常心拍定位。
6. XGBoost 风险分级。
7. SHAP 解释。
8. 报告和健康建议生成。

### 3. 查看结果

分析完成后查看：

- 风险等级和风险评分。
- CNN 异常心拍数量及置信度。
- XGBoost 风险等级、风险概率及置信度。
- 双通路复核状态。
- ECG 波形、R 峰和异常心拍标记。
- 12 项临床特征及其状态。
- SHAP 单样本贡献、全局特征重要性、QRS 与 ST_shift 交互图、单样本决策路径。
- 结构化健康建议和医生沟通话术。

### 4. 导出报告

在“筛查报告”区域：

- 点击“下载 TXT”导出文本报告。
- 点击“下载 PDF”导出包含患者信息、波形、特征、SHAP 和建议的 PDF 报告。
- 可以使用复制或打印功能辅助沟通和存档。

## 结果解读

### 风险等级

- **低危**：XGBoost 输出的整体风险等级较低，但仍需结合波形、症状和临床资料判断。
- **中危**：提示需要进一步关注和专业复核。
- **高危**：提示需要优先进行医生复核，不代表系统已经作出医学诊断。

风险等级来自 XGBoost 数值特征通路，不等同于某一种具体疾病结论。

### 双通路结果

- **CNN 形态通路**只负责定位可能异常的心拍。
- **XGBoost 数值通路**只负责基于 12 项特征进行整体风险分级。
- 系统不会自动把两个结果合成为一个新的风险预测。
- 当两条通路结果不一致时，应优先进行人工复核。

### 置信度

- CNN 置信度根据逐心拍预测类别置信度汇总得到。
- XGBoost 置信度为三类风险概率中的最大值。
- 默认低置信度阈值为 `0.8`，可以在 `config.json` 中配置。
- 任一通路置信度低于阈值时，复核状态会标记为“低置信度”。

### 复核状态

系统可能显示以下状态：

- **双通路一致-高风险**：CNN 检出异常心拍，XGBoost 输出中危或高危。
- **通路冲突-波形异常**：CNN 检出异常心拍，但 XGBoost 输出低危。
- **通路冲突-风险偏高**：CNN 未检出异常心拍，但 XGBoost 输出高危。
- **双通路一致-低风险**：CNN 未检出异常心拍，XGBoost 输出低危。
- **低置信度**：任一通路置信度低于配置阈值，优先提示人工复核。

这些状态用于辅助复核，不是自动诊断结论。

### SHAP 图

SHAP 仅解释 XGBoost 的 12 项临床特征，不解释 CNN 的深度波形特征。

- **单样本贡献图**：显示当前样本各特征对目标类别的正向或负向贡献。
- **全局特征重要性图**：基于 `training_data.csv` 样本集合，显示平均绝对 SHAP 贡献。
- **QRS 与 ST_shift 交互图**：观察 QRS 对模型输出的贡献与 ST_shift 之间的关系。
- **单样本决策路径图**：从 base value 开始，逐步叠加各特征贡献，展示到最终模型输出的路径。
- 页面会显示当前 SHAP 解释目标类别：低危、中危或高危。

如果训练数据不足、文件不可读或历史记录没有保存详细 SHAP 数据，系统会显示提示，不会强行生成缺失图表。

## 健康建议说明

系统使用本地 JSON 建议库生成结构化内容，建议库文件为 `config/suggestions.json`。每条建议包含：

- 给医生的专业建议。
- 给患者的通俗解释。
- 医生沟通话术。
- 复查建议。
- 生活方式建议。
- “仅供参考，请咨询医生”提示。

建议匹配会参考 CNN 状态、XGBoost 风险等级、异常程度和关键异常特征，例如 QTc、HR、ST_shift 和 QRS。

建议库默认离线运行，不依赖大模型 API。健康建议不能代替医生判断，必须由医护人员审核后用于沟通。系统不会根据建议库直接作出疾病诊断。

## 常见问题

### 1. 点击示例数据后提示文件不存在怎么办？

请确认在项目根目录启动系统。示例数据按钮使用配置中的 MIT-BIH 数据目录，并读取 `100.dat`；该文件必须与同目录的 `100.hea` 配套存在。

### 2. DAT 文件为什么不能单独使用？

MIT-BIH DAT 文件需要对应的 HEA 头文件提供记录信息。请将同名的 DAT 和 HEA 文件放在同一目录。

### 3. 为什么分析结果中没有 SHAP 图？

可能原因包括模型不可用、SHAP 计算失败、训练数据缺少 12 项特征列，或历史记录只保存了旧版本的单样本结果。系统会保留可用结果并提示缺失原因。

### 4. 为什么历史记录中没有波形？

新版本记录会将波形单独保存到 `storage/waveforms/`。如果波形文件被删除、移动，或记录来自旧版本，则无法恢复完整波形。

### 5. 修改 QTc 阈值后什么时候生效？

在“系统设置”中保存设置后，新分析会使用新的配置。分析页面本次选择的性别优先于默认性别。

### 6. 大模型接口是否必须配置？

不需要。当前建议库默认使用本地离线规则。LLM 字段属于可选配置，不能替代本地风险分析，也不参与 CNN 或 XGBoost 风险预测。

### 7. 系统是否支持 12 导联？

不支持。当前系统输入约束为单导联 ECG。

### 8. 报告中的指标能否作为临床性能证明？

不能。当前训练数据量有限，训练标签依赖已有数据或规则生成，缺少医生独立标注测试集。现有评估结果仅供参考：

- XGBoost 高危样本敏感性：未能验证。
- CNN 各类型心律失常敏感性：未能验证。
- 申报书要求的 7:2:1 独立测试划分：未能验证。
- 真实临床验证和真实端到端性能：未能验证。

### 9. 如何重新开始一次分析？

在结果页面点击“重新分析”；如需同时清除当前已选文件，点击“清空结果”。
