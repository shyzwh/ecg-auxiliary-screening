# 用户手册

## 1. 概述

本系统为 ECG 心电风险辅助筛查平台，面向临床辅助判读、教学演示和病历复核场景。用户可上传 ECG 文件，系统会执行信号预处理、R 峰检测、特征提取、异常心拍定位、整体风险分级和报告生成。

## 2. 适用场景

- ECG 文件上传与分析
- 历史筛查记录管理
- 病情统计查看
- 病例教学学习
- 系统设置与后台 AI 润色功能

## 3. 快速开始

### 3.1 环境准备

1. 安装 Python 3.10 或更高版本。
2. 进入项目根目录。
3. 执行：

```bash
pip install -r requirements.txt
```

### 3.2 启动应用

```bash
streamlit run app.py
```

打开浏览器访问：

```text
http://localhost:8501
```

## 4. 页面说明

### 4.1 心电分析

- 支持上传 CSV、TXT、DAT 以及 NPY ECG 文件。
- 可加载示例数据进行演示。
- 执行分析后，可查看波形、R 峰位置、异常心拍、SHAP 解释和报告。

### 4.2 历史记录

- 保存分析结果到本地 `storage/records.json`。
- 可查看历史筛查记录。
- 支持按时间和风险状态快速检索。

### 4.3 病情统计

- 汇总分析样本的年龄、风险分布和异常特征情况。
- 统计数据基于已保存历史记录，空值和异常值会被清洗后再计算。
- 统计页面对缺失 age 字段会自动忽略，避免虚假的平均年龄为 0。

### 4.4 病例教学

- 提供典型 ECG 案例供学习和对照。
- 每个案例包括描述、临床分析、关键学习点和处理建议。

### 4.5 系统设置

- 提供基础显示和参数配置。
- 在后台密钥代理模式下，不显示密钥输入框。
- 提供“测试连接”入口，检查 AI 润色服务是否可用。

## 5. AI 润色功能

AI 润色默认保持离线模式。用户可在报告页点击“AI 润色”，系统会优先使用离线建议，必要时按后台密钥代理调用 GLM 接口生成更自然的医患沟通文本。

说明：

- 真实 API 密钥不在前端显示。
- 若后台未配置，系统会提示：`后台服务未配置，AI润色不可用`。
- 若接口访问失败，系统会自动回退离线建议，并给出提示。

## 6. 注意事项

- 本系统输出仅为辅助筛查，不替代专业医生诊断。
- 真实 API 访问受服务端限流影响，可能出现 429 等错误。
- 对于较大或异常数据，建议优先检查格式和采样率是否正确。

## 7. 故障排查

- 上传失败：检查文件格式和编码是否正常。
- 统计页面为空：检查历史记录文件是否存在且字段格式是否正常。
- AI 润色不可用：检查后台密钥和服务端配置。
- 模型预测异常：确认模型文件和 `config.json` 配置是否正确。

## 8. 交付说明

本手册基于当前代码实际功能整理，不加入虚构能力或超出实现范围的描述。系统中涉及的风险提示、报告生成和 AI 润色能力都采用保守、可回退的方式部署。
