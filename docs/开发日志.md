# 开发日志

## 项目概览

本项目为基于 Streamlit 的 ECG 风险辅助筛查系统，定位为医疗辅助分析工具。系统依赖 ECG 信号预处理、R 峰检测、12 项 HRV/波形特征提取、1D-CNN 异常心拍定位以及 XGBoost 风险分级，并在结果页面展示 SHAP 解释与结构化报告。

## 关键问题与修正记录

### 1. 病情统计崩溃

- 根因：历史记录存在混合类型字段和空值，直接转换为 DataFrame 时触发异常。
- 修正：在聚合和计算前进行字段归一化、年龄提取和空值清洗。

### 2. 平均年龄为 0

- 根因：缺失年龄值被错误当作 0 参与统计。
- 修正：只统计有效年龄，缺失值在统计中忽略。

### 3. 历史记录空白长条

- 根因：记录结构不统一，缺失字段导致条形图绘制失败。
- 修正：对记录执行统一字段映射和分组逻辑。

### 4. AI 润色访问失败

- 现象：真实 API 访问可能返回 429 流量限制。
- 结论：这是服务端限流，不属于本地代码错误；系统已保留离线建议作为稳定回退。
