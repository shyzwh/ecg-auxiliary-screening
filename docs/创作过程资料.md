## 4. 遇到的问题及解决方案

| 问题 | 处理方式 |
|---|---|
| 项目路径依赖当前工作目录 | 使用项目根目录和配置路径解析，修复 SHAP 路径问题 |
| 页面主题和风险颜色不统一 | 统一全局 CSS、风险颜色和趋势图样式 |
| 历史记录结构和空值影响统计 | 在服务层统一读取，统计前处理患者、年龄和特征字段 |
| API 429 或超时 | `_call_glm_api` 按三个模型顺序尝试，每个模型一次，全部失败返回 `None` |
| 外部 AI 不可用 | 保留离线规则报告和前端回退提示 |
| SQLite 字段名历史不一致 | 增加 `database/migrate_filename_column.py`，将 `文 件名` 迁移为 `文件名` |
| 模型指标边界不清晰 | 在评估文件和文档中标注 80/20、标签来源和未验证类别 |
